# Angular Todo List

A simple todo list app built with Angular.

## Task

Add a new todo form and show the new todo at the top of the list.

## Features

- Load todos from [DummyJSON](https://dummyjson.com/todos)
- Add a new todo with a form (button or Enter key)
- New todo appears at the top of the list
- Send the new todo to the API (POST)
- Loading state on the Add button while saving
- Prevents adding the same todo twice while loading

## Tech

Angular, Signals, HttpClient, Router

## Run

```bash
npm install
ng serve
```

Then open http://localhost:4200
